# 4. 클로드 코드 사용해보기

## 안전하게 작업하기

`Shift + Tab`을 눌러 클로드의 작업 권한을 변경할 수 있습니다.

**세 가지 모드:**

1. **기본 모드**: 파일 수정과 명령어 실행 전에 항상 물어봄
2. **자동 편집 모드**: 파일은 자동으로 수정하지만 명령어 실행은 물어봄
3. **계획 모드**: 실행 전 계획만 세우고 승인을 기다림

---

## 효과적으로 사용하기

### 1. 클로드에게 직접 물어보기

클로드 사용법이 궁금하면 바로 물어보세요.

**예시:**

- "훅은 어떻게 설정하나요?"
- "CLAUDE.md는 어떻게 작성하나요?"

**유용한 명령어:**

- `/init` - 프로젝트용 CLAUDE.md 파일 만들기
- `/agents` - 맞춤 에이전트 설정하기
- `/doctor` - 설치 문제 진단하기

### 2. 대화하듯 요청하기

완벽한 명령어가 필요 없습니다. 원하는 것을 말한 후 대화로 다듬어가세요.

```
사용자: 이 보고서 요약해줘
클로드: [요약을 시도함]

사용자: 좀 더 짧게, 3줄로만 정리해줘
클로드: [더 짧게 요약함]
```

### 3. 언제든 중단하고 방향 수정

클로드가 잘못된 방향으로 가면 즉시 입력해서 수정할 수 있습니다.
끝날 때까지 기다리거나 처음부터 다시 시작할 필요가 없습니다.

### 4. 처음부터 구체적으로 요청하기

명확할수록 수정이 적습니다.

**모호한 요청:**

```
이 문서 정리해줘
```

**구체적인 요청:**

```
이 회의록에서 결정사항만 추출해서 번호 목록으로 만들어줘.
각 항목마다 담당자와 기한을 표시해줘.
```

### 5. 검증 기준 제공하기

클로드가 스스로 확인할 수 있는 기준을 주세요.

**예시:**

```
고객 이메일 목록에서 중복을 제거해줘.
이메일 형식이 올바른지 확인하고,
형식이 잘못된 건 따로 표시해줘.
```

### 6. 복잡한 문제는 계획부터

어려운 작업은 계획부터 세우세요.

**2단계 접근:**

1. **계획 모드로 분석** (`Shift + Tab` 두 번)

```
이 폴더에 있는 경쟁사 분석 자료를 모두 읽고
비교 보고서를 어떻게 구성하면 좋을지 계획 세워줘.
```

2. **계획 검토 후 실행**

- 계획을 확인하고 대화로 다듬기
- 승인 후 클로드가 실행
