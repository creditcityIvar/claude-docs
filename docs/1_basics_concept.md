# 클로드 기본 개념

## 클로드란?

Anthropic이 개발한 AI 언어 모델입니다. 대화, 코드 작성, 문서 분석 등 다양한 작업을 수행할 수 있습니다.

## 클로드 코드란?

> 클로드가 **내 컴퓨터에 있는 파일을 직접** 읽고 수정할 수 있게 해주는 도구.

클로드를 터미널과 IDE에서 사용할 수 있게 해주는 공식 CLI 도구입니다.  
파일 편집, 코드 검색, Git 작업 등 개발 작업에 특화되어 있습니다.

## 왜 클로드 코드?

웹이나 앱으로 클로드를 사용할 때는 파일 내용을 복사하고 붙여넣어야 합니다.

클로드 코드를 사용하면 클로드가 **내 컴퓨터에 있는 파일을 직접** 읽고 수정할 수 있습니다.

## 클로드 코드 작동 원리

### Agentic Loop

![Agentic Loop](images/agentic-loop.svg)

클로드에게 작업을 시키면 아래와 같은 단계를 반복합니다.

**정보 수집 → 실행 → 결과 확인**

1. **정보 수집** (Gather context): 맥락을 파악하기 위해 파일을 읽습니다.
2. **실행** (Take action): 파일을 수정하거나 명령어를 실행합니다.
3. **결과 확인** (Verify results): 작업이 제대로 되었는지 확인합니다
4. 완료될 때까지 1-3을 반복하거나, 작업이 끝나면 종료합니다

사용자 역시 이 루프의 일부입니다. 루프 중간에 언제든지 중단하거나 방향을 수정할 수 있습니다.

### Agentic Loop 예시

**"내 회의 메모들을 읽고 정리된 보고서를 만들어줘"**라고 요청하면:

1. **정보 수집**: 폴더에서 회의 메모 파일들을 찾아 읽기
2. **실행**: 메모 내용을 분석하고 주제별로 정리된 보고서 문서 작성
3. **사용자 개입**: 작업 중 "작년 분기 보고서도 참고해서 형식을 맞춰"라고 추가 요청
4. **정보 수집**: 작년 분기 보고서를 찾아 읽고 형식 파악
5. **실행**: 작년 보고서 형식에 맞춰 현재 보고서 재작성
6. **결과 확인**: 생성된 보고서를 검토하여 형식과 내용이 적절한지 확인
7. **반복**: 누락된 내용이 발견되면 다시 회의 메모를 읽고(정보 수집) 보고서에 추가(실행)

## Model ← Claude Code → Tools

Agentic loop는 두 가지 핵심 요소로 작동합니다:

- **Model (모델)**: 클로드 AI - 추론하고 판단합니다
- **Tools (도구)**: 파일 읽기/수정, 명령어 실행 등 작업을 수행합니다
- **Claude Code (클로드 코드)**: 둘을 연결하는 다리 역할

클로드 코드가 있으면 클로드 모델로 생각하고 도구로 파일을 읽고 수정할 수 있게 됩니다.

## Tools (도구)

도구 없이는 클로드가 텍스트로만 응답할 수 있습니다.
도구가 있으면 클로드가 실제로 행동할 수 있습니다:

코드를 읽고, 파일을 수정하고, 명령어를 실행하고, 웹을 검색하고, 외부 서비스와 상호작용할 수 있습니다.

### 기본 제공 툴

| 카테고리            | 클로드가 할 수 있는 작업                                                              |
| ------------------- | ------------------------------------------------------------------------------------- |
| **파일 작업**       | 파일 읽기, 코드 수정, 새 파일 생성, 이름 변경 및 재구성                               |
| **검색**            | 파일 찾기, 내용 검색, 코드베이스 탐색                                                 |
| **실행**            | 셸 명령어 실행, 서버 시작, 테스트 실행, git 사용                                      |
| **웹**              | 웹 검색, 문서 가져오기, 오류 메시지 조회                                              |
| **코드 인텔리전스** | 수정 후 타입 오류와 경고 확인, 정의로 이동, 참조 찾기 (코드 인텔리전스 플러그인 필요) |

각 도구 사용은 정보를 반환하고, 이 정보가 다시 루프로 들어가 클로드의 다음 결정에 영향을 줍니다.

### 추가 제공 툴

| 카테고리         | 클로드가 할 수 있는 작업                           |
| ---------------- | -------------------------------------------------- |
| **서브에이전트** | 복잡한 작업을 하위 에이전트에게 위임하여 병렬 처리 |
| **사용자 질문**  | 불확실한 부분이나 선택사항에 대해 사용자에게 질문  |
| **작업 조율**    | 여러 작업의 우선순위 관리 및 워크플로우 조정       |

### 기본 기능 확장하기

| 확장 기능         | 설명                                                |
| ----------------- | --------------------------------------------------- |
| **스킬 (Skills)** | 특정 작업에 대한 전문 지식과 지침을 클로드에게 제공 |
| **MCP**           | Slack, GitHub 등 외부 서비스와 연결하여 데이터 접근 |
| **훅 (Hooks)**    | 특정 이벤트 발생 시 자동으로 명령어 실행            |

이러한 확장 기능들은 핵심 agentic loop 위에 레이어를 형성합니다. 이에 대해서는 이후 장에서 자세히 정리할게요.
